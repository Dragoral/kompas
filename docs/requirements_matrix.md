## Актуализация после технических исправлений (19.10.2026)

- Исправлены порядок и область подсчёта доз: только активное назначение, стабильная хронологическая сортировка.
- В правило низкой приверженности добавлен минимум 6 учтённых доз для защиты от ранних ложных алертов.
- Закрытые алерты не должны пересоздаваться на старых данных; повторное оповещение допускается только при обнаружении более новых данных источника.
- Добавлена фиксация разбора нежелательного явления врачом.
- Ошибки форматирования шаблона SMS переводятся на резервный текст и фиксируются в журнале проблем, а не прерывают обработку пациента.
- Неуспешный TOTP увеличивает счётчик ошибок и журналируется; повтор кода в том же временном окне запрещён. Добавлена миграция `totp_last_step`.
- Запрет администраторского сброса пароля пациенту; системные метрики доступны только администраторам.
- SSE использует временное перекрытие и дедупликацию ID; врач получает глобальные живые уведомления и отправляет квитанцию доставки.
- В `useApi` исключён показ результатов предыдущей карточки при смене пациента. Нормализуются timezone-aware отметки времени офлайн-синхронизации.
- API не публикуется напрямую на хост через compose; добавлены README, `.env.example` и команда первичного создания администратора без очистки БД.
- **Тесты:** backend pytest вывел `59 passed in 20.22s`; в песочнице процесс после итоговой строки не завершился штатно и был остановлен окружением. Две целевые проверки новых сценариев прошли и завершились нормально (`2 passed`). Для тестирования использовался временный тестовый shim `pyotp` вне состава проекта, так как пакет отсутствует в образе среды.
- **Не проверено runtime в этой среде:** frontend typecheck/build/lint (npm зависимости отсутствуют, офлайн-кэш неполон), Docker Compose, реальные SMS/телефонные интеграции, миграция существующей production-БД и живой PostgreSQL backup/restore.
- **Статические проверки:** `compileall` для Python прошёл; 20 YAML-справочников разбираются без синтаксических ошибок; все 64 `.ts`/`.tsx` файла прошли синтаксический разбор без ошибок. Это не равно полному TypeScript typecheck или сборке.
- **Остаётся клинической задачей:** сверка справочников с актуальными официальными источниками. Флаги `verified` не изменялись автоматически.
