# Реестр нормативных требований и стандартов

Для каждой нормы указано: что требует → как реализовано в системе → статус.

**Статусы:**
- ✅ реализовано в прототипе;
- 🟡 частично или есть заглушка-адаптер;
- 🔵 организационная мера или мера для промышленной эксплуатации (вне рамок хакатона, описан путь).

**Достоверность:**
- **[П]** — проверено по первоисточнику (полному тексту акта);
- **[В]** — по вторичным источникам (справочно-правовые системы, профильные обзоры). Перед промышленным внедрением сверить с актуальной редакцией на [pravo.gov.ru](http://publication.pravo.gov.ru).

Дата составления: 17.10.2026.
