# Отчёт о проверке интеграции frontend/backend

Дата: 19 октября 2026 г.

## Объём интеграции

- Инвентаризировано 93 комбинации HTTP-метода и пути, зарегистрированные FastAPI в `backend/app/main.py`.
- Для каждого функционального маршрута указана frontend-страница или компонент в `docs/frontend-backend-coverage.md`.
- Сохранены раздельные ролевые маршруты, серверная авторизация, TOTP для подключённых/обязательных MFA-учётных записей, ограничение по роли клинического рецензента и подтверждение клинических действий врачом.
- Врачебная сводка пациентов имеет отдельные фильтры; список для категории «Требуют внимания» поддерживается серверным `needs_attention`.
- Пациентская офлайн-очередь хранит разрешённые типы записей в IndexedDB в шифрованном виде Web Crypto AES-GCM и синхронизирует их через `/api/me/sync`.

Статическая матрица покрытия содержит все **93 комбинации метода/пути и 84 уникальных API-пути**. Проверка `python tools/check_route_coverage.py` завершилась успешно: все 84 пути отражены в `docs/frontend-backend-coverage.md`.

## Дополнительная проверка безопасности

- Публичный `/api/ready` не раскрывает имена внутренних компонентов, тексты исключений и `last_error`; подробности остаются только в авторизованном `/api/admin/system`. Добавлен тест регрессии. `/api/metrics` отражён в матрице как административный endpoint, что совпадает с backend-проверкой роли.

## Ограничения перед релизом

1. Повторить все backend-тесты с официальными зависимостями, особенно TOTP/MFA-тесты.
2. Выполнить `npm ci`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` в окружении с доступом к npm registry.
3. Протестировать SSE, подтверждение доставки алертов, offline/online, IndexedDB и восстановление Service Worker в поддерживаемых браузерах.
4. На целевом стенде проверить PostgreSQL, резервную копию/восстановление, доставку SMS и производительность под нагрузкой.
5. Не использовать непроверенные клинические справочники для реального ведения пациентов; их верификация и production-готовность требуют отдельного клинического и юридического подтверждения.
